# Reporting a security problem / Báo lỗ hổng bảo mật

Found a problem in Nostalgia or Nos Turbo, especially a token leak or a way to make the launcher
install a file we did not sign?

- Email **nostalgialauncher@gmail.com** with "Security" in the subject.
- We answer within 72 hours.
- Please do not post it publicly before a fix is out.
- Include the version, your operating system and the steps to reproduce it.

Thấy lỗ hổng (rò token, cài được file không có chữ ký của chúng tôi...)? Gửi email tới
nostalgialauncher@gmail.com, tiêu đề có chữ "Security". Chúng tôi trả lời trong 72 giờ. Xin đừng
đăng công khai trước khi có bản vá.

Only trust downloads from this repository's Releases and <https://nostalgiamc.org/>. See
[AN-TOAN.md](AN-TOAN.md).
